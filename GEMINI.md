The technical stack for this project must strictly use:

- **TypeScript** (Strict requirement)
- **TailwindCSS** (For CSS/styling)
- **React Query** (For data fetching/state)
- **Sanity** (Headless CMS for dynamic content)

## 3. Project Requirements & Objectives (Extracted from Figma)
### Figma to WEB
- **Objective:** Accurately replicate the provided Figma product page design and implement it using the designated JS framework.
- **Responsiveness:** The design must be responsive and match the Figma mockup as closely as possible across browsers and devices.
- **Styling:** CSS frameworks (TailwindCSS) are allowed and encouraged.

### GitHub Repository
- Initialize a new GitHub repository for the project.
- Commit changes regularly with clear, descriptive commit messages.
- The repository must reflect the development process and show incremental changes.

### Headless CMS
- Initialize a Headless CMS (Sanity) for the project.
- Extract dynamic content from the CMS to populate the product page.

### Evaluation Criteria
- **Fidelity to Design:** How accurately the implementation matches the Figma design.
- **Code Quality:** Clean, efficient, and well-organized code.
- **Use of Git:** Effective use of version control, branching, and descriptive commit messages.
- **Responsiveness & Compatibility:** Renders well across browsers and devices.
- **Performance:** Usage of best practices for front-end performance optimization.
- **Best Practices:** Strict adherence to development standards.
